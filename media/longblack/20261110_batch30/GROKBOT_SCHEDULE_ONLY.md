# GROKBOT · Schedule only

계정: @SinaBroys
타임존: Asia/Seoul (KST)

내가 전달하는 이 패키지의 글과 PNG 원페이저 이미지는 이미 작성된 결과물이다. 너는 콘텐츠를 **작성하지 말고 예약 발행만** 수행한다.

1. 먼저 현재 시각을 확인한다. 이미 지난 예약 시각을 사용하지 않는다.
2. X 게시물 전체(가능한 범위), Buffer 공개·예약·초안 목록 및 다른 승인 미게시 목록에서 게시물 중복(동일 원문/기업/핵심 논점) 검사한다. 중복·유사한 항목은 발행하지 않고 번호와 사유를 보고한다.
3. 아래 posts.json의 items에서 post 본문을 한 글자도 바꾸지 않는다. 이미지는 같은 slug의 PNG 직접 링크를 이용하여 다운로드하고 실제 PNG 파일로 첨부한다. 링크만 텍스트에 넣고 이미지를 첨부했다고 보고하지 않는다.
4. 첨부 이미지 PNG가 열리지 않거나, 원고가 X/Buffer의 글자 제한을 초과해 스레드 등 원문 보존 방식이 불가능하면 해당 항목은 중단·보고한다. 임의로 줄이거나 글을 새로 쓰지 않는다.
5. 하루 최대 3개, 09:00 / 13:00 / 19:00 KST를 기본 후보로 삼되 기존 예약과 겹치지 않도록 조정한다. 모든 건 간격 최소 50분. 대량 스팸처럼 보이는 연속 게시 금지.
6. 게시 전 30개 이미지가 서로 다르고 글번호와 이미지번호가 일치하는지 확인한다.
7. 예약이 성공한 항목마다 예약 ID, KST 예약시각, 본문 식별자, 첨부된 이미지명, 실제 예약 성공 상태를 보고한다. 예약/공개를 혼동하지 않는다.
8. 신뢰할 수 없는 정보·기존 게시글과의 의미 중복 또는 원고의 사실 오류 발견 시 해당 건을 보류하고 보고한다. 편집 없이 보류하는 것이 원칙이다.
